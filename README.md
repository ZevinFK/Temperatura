# 🌡️ Monitor de Temperatura

Projeto desenvolvido em linguagem C para monitoramento da temperatura de uma máquina.

## 📌 Sobre o projeto

O programa permite definir uma temperatura limite, registrar temperaturas e gerar um relatório com os principais dados coletados.

O sistema também possui uma condição de segurança que identifica **3 temperaturas consecutivas acima do limite** e interrompe o monitoramento.

## ⚙️ Funcionalidades

- Definição da temperatura limite;
- Registro de temperaturas;
- Validação das temperaturas entre 0°C e 75°C;
- Cálculo da temperatura média;
- Identificação da maior temperatura;
- Identificação da menor temperatura;
- Contagem de temperaturas acima do limite;
- Detecção de 3 temperaturas consecutivas acima do limite;
- Relatório final dos dados registrados.

## 🛠️ Tecnologias

- Linguagem C
- GCC
- Terminal/Console
